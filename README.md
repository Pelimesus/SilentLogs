# 🧹 SilentLogs

[English](#english) | [Русский](#русский)

---

## English

A simple client-side Fabric mod for Minecraft 1.21.4 that cleans up and hides server IP addresses and connection clutter from client log files.

### Features
- Hides server IP and connection details in client log files.
- Replaces log outputs with clean, minimal references.
- Lightweight and fully compatible with performance/optimization mods.

### Screenshots
![Logo](src/main/resources/assets/silentlogs/icon.png)

### Installation
1. Download **SilentLogs** from the [Releases](../../releases) section.
2. Drop the `.jar` file into your `.minecraft/mods` folder.
3. Make sure you have **Fabric Loader** installed.

## Русский

Простой клиентский Fabric-мод для Minecraft 1.21.4, который очищает логи и скрывает IP-адреса серверов и лишний мусор из файлов логов.

### Особенности
- Скрывает IP-адреса и детали подключения в клиентских логах.
- Заменяет вывод в консоль на чистые и минималистичные записи.
- Легковесный и полностью совместимый с модами на оптимизацию.

### Скриншоты
![Logo](src/main/resources/assets/silentlogs/icon.png)

### Установка
1. Скачайте **SilentLogs** из раздела [Releases](../../releases).
2. Положите `.jar` файл в папку `.minecraft/mods`.
3. Убедитесь, что у вас установлен **Fabric Loader**.
