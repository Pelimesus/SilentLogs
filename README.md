**# SilentLogs

A simple client-side Fabric mod for Minecraft 1.21.4 that cleans up and hides server IP addresses from client log files.

## Features
- Hides server IP and connection details in client log files.
- Replaces log outputs with clean static references.
- Lightweight and fully compatible with optimization mods.

## Installation
1. Download **SilentLogs** from the Releases section.
2. Drop the `.jar` file into your `.minecraft/mods` folder.
3. Make sure you have **Fabric Loader** and **Fabric API** installed.
